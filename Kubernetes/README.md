# Kubernetes

Hands-on Kubernetes lessons and practical labs.

## Lessons

- [kubernetes-01-installation-ec2](./kubernetes-01-installation-ec2/) — Install a Kubernetes cluster on AWS EC2 using kubeadm, containerd, and Flannel.
- [kubernetes-02-basic-operations](./kubernetes-02-basic-operations/) — Pods, ReplicaSets, Deployments, namespaces, rolling updates, and rollbacks.
- [kubernetes-03-networking-and-service-discovery](./kubernetes-03-networking-and-service-discovery/) — Services, ClusterIP, NodePort, DNS, endpoints, and cross-namespace service discovery.
- [kubernetes-04-volumes-and-persistent-storage](./kubernetes-04-volumes-and-persistent-storage/) — PersistentVolumes, PersistentVolumeClaims, emptyDir, StorageClasses, and dynamic provisioning.
- [kubernetes-05-secrets](./kubernetes-05-secrets/) — Secret types, credentials, registry authentication, ServiceAccount tokens, and bootstrap tokens.
- [kubernetes-06-microservices-and-hpa](./kubernetes-06-microservices-and-hpa/) — Deploy a Node.js/MongoDB ToDo application and practice Metrics Server and Horizontal Pod Autoscaling.
- [kubernetes-07-eks-cluster-and-cluster-autoscaler](./kubernetes-07-eks-cluster-and-cluster-autoscaler/) — Create an Amazon EKS cluster, configure worker nodes, IRSA, and Cluster Autoscaler.
- [kubernetes-08-eks-ingress-and-dynamic-volume-provisioning](./kubernetes-08-eks-ingress-and-dynamic-volume-provisioning/) — Create an EKS cluster, configure Ingress path/host routing, practice rewrite-target, and dynamically provision EBS volumes.
- [kubernetes-09-pod-scheduling](./kubernetes-09-pod-scheduling/) — Control Pod placement with nodeName, nodeSelector, node affinity, Pod affinity, taints, and tolerations.
- [kubernetes-10-container-health-probes](./kubernetes-10-container-health-probes/) — Configure liveness, readiness, and startup probes using HTTP, TCP, and exec checks.

More Kubernetes lessons will be added here as the learning journey continues.
